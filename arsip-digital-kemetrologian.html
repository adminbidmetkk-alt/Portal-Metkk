Hubungkan Folder Arsip

Pilih folder di komputer/server Anda sebagai lokasi penyimpanan arsip. Semua berkas dan datanya akan tersimpan langsung di folder tersebut, sehingga dapat diakses kapan pun — bahkan tanpa aplikasi ini.

Fitur pilih-folder memerlukan browser berbasis Chromium (Google Chrome atau Microsoft Edge) versi terbaru di komputer desktop. Setiap kali halaman ini dibuka ulang, folder perlu dihubungkan kembali (satu kali klik) karena ini adalah aturan keamanan browser.

Tambah Arsip

Lengkapi data berkas. Berkas akan disimpan otomatis ke dalam folder arsip sesuai tahunnya.
📎 Klik untuk pilih berkas (PDF/JPG/PNG), atau seret ke sini

Scan Berkas

Gunakan kamera perangkat untuk memindai dokumen langsung dari browser.
Posisikan dokumen rata di dalam bingkai, lalu tekan Ambil Gambar.
Browser tidak dapat mengakses scanner fisik (TWAIN/WIA) secara langsung. Jika berkas sudah dipindai lewat aplikasi scanner/printer, gunakan tombol Tambah Arsip → pilih berkas untuk mengunggahnya.
